# Sex differences in differentially expressed genes in early-life stress induce chronic primary low back pain in rats
In this study, a snRNA seq analysis was performed in stress vs non-stressed animals to identify differentially expressed genes using the dorsal horn spinal cord tissue collecte post-perfusion from the animals.

# Overview

This repository contains the analysis pipeline and scripts for single-nucleus RNA sequencing (snRNA-seq) data processing, quality control, and downstream analysis.
The workflow is designed to handle raw sequencing data through to publication-ready figures, following best practices for reproducibility and transparency.

The analysis includes:
Preprocessing and quality control
Normalization and dimensionality reduction
Clustering and cell type annotation
Differential expression analysis
Visualization of results (UMAP/t-SNE, heatmaps, violin plots, etc.)
